KernScript Scripting Language
============================

Status: UNIMPLEMENTED. Compiler::compile
(Lib/Impl/source/comp/Compiler.cpp) always returns false, and every
Parser sub-parser (parseVariableDeclaration, parseFunction,
parseExternFunction, parseIf, parseElse, parseWhile, parseReturn,
parseBlock in Lib/Impl/source/comp/Parser.cpp) returns false, so no
non-trivial source currently compiles. Do not write new scripts in
this language; use the assembly language (Assembly Language.txt).

What exists today:

- The Parser registers the keywords var, func, extern, true, false,
  if, else, while, return, and its top-level parse() dispatches on
  func and extern. But parseFunction always fails (it unconditionally
  returns false after the header), and parseExternFunction always
  fails, so even a minimal `func` program does not parse.
- The retained grammar intent (kept from the original stub):

Function : 'func' Identifier '(' Identifier (',' Identifier)* ')' Block
Block : '{' Statements* '}'

Once a compiler exists, this document should grow a real
specification (declarations, parameters, control flow, extern
return-chaining, string comparison rules, step budget) verified
against that implementation, mirroring the corresponding sections of
the assembly document. Until then, every claim about scripting
semantics here would be fiction.
